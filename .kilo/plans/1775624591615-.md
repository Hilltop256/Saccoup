# Member Onboarding: Invitation System Plan

## Current State Analysis

### Where Invite Codes Are Generated/Displayed
1. **GroupsPage.tsx** (lines 227-251): Shows invite code with copy button, copy invite link button, and regenerate button (chairman only)
2. **SettingsPage.tsx** (lines 385-398): Shows group invite code with copy button
3. **MembersPage.tsx** (lines 91-117): Shows invite code when adding a member

### Who Has Permission to Send Invitations
- **Add members**: `admin`, `super_admin`, `chairperson`, `chairman`, `secretary` (MembersPage.tsx:53-55)
- **Regenerate invite code**: Only `chairperson` (GroupsPage.tsx:242-251)

## Issue
The invite code is hidden in settings or after adding a member. Users don't see a clear "Invite" flow to get the code and share it.

## Proposed Solution

### Add "Invite Members" Button and Modal
1. Add a prominent "Invite Members" button in GroupsPage header
2. Create an InviteModal component showing:
   - Group invite code with copy button
   - Shareable invite link with copy button
   - Option to regenerate code (chairperson only)
   - Clear instructions on how to share

### Files to Create/Modify
- `src/components/saccoUp/InviteModal.tsx` - New modal component
- `src/components/saccoUp/GroupsPage.tsx` - Add invite button in header

### Implementation Steps
1. Create InviteModal component with invite code, link display, copy buttons
2. Add "Invite Members" button to GroupsPage header (visible to authorized roles)
3. Integrate modal with existing dataService for code retrieval/regeneration
