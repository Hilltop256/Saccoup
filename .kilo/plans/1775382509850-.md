# Plan: Add ROSCA Columns to Financial Spreadsheet

## Goal
Add ROSCA (Merry-Go-Round) tracking columns to the Financial Spreadsheet page for tracking draws, contributions, amounts received, security savings, and balances.

## Current State
- SpreadsheetPage (`src/components/saccoUp/SpreadsheetPage.tsx`) has tabs for:
  - Contributions (member due/paid/balance)
  - Expenses
  - Financial Summary (bank balance, investments)
- Currently tracks basic contribution data per member per period

## Implementation Plan

### 1. Add New ROSCA Tab to SpreadsheetPage
- Add "ROSCA" as a new tab alongside Contributions, Expenses, Financials
- ROSCA tab will display member-level ROSCA data

### 2. ROSCA Tab Columns
Add the following columns per member:
- **Draw 1-10 Monthly Contribution**: Track contribution per draw (10 columns)
- **Amount Received**: Total amount received (winnings)
- **Security/Savings**: Security deposit savings
- **Balance**: Current balance (contributions - received + security)

### 3. Data Integration
- Fetch ROSCA cycle data from `rosca_cycles` and `rosca_draws` tables
- Link draws to members via winner_name or winner_id
- Calculate totals per member

### 4. UI Implementation
- Inline editable cells for contributions
- Auto-calculated columns for Amount Received, Security, Balance
- Summary row showing totals
