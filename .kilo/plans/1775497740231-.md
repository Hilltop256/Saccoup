## Implementation Plan

### Phase 1: Fix Merry Go Round Contributions Persistence (Priority)

**Current State (RoscaPage.tsx lines 699-748)**:
- UI shows members as clickable buttons
- Click cycles: Pending → Paid → Defaulted
- BUT: Only saves to React state, shows toast - **NOT persisted to database**

**Fix**: 
1. Add database table `rosca_contributions` to persist payment status
2. Update `dataService.ts` with save/load functions
3. Make the existing UI actually save to database

**Database Schema**:
```sql
CREATE TABLE rosca_contributions (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  cycle_id UUID REFERENCES rosca_cycles(id),
  draw_number INTEGER,
  member_id UUID REFERENCES members(id),
  member_name TEXT,
  amount INTEGER DEFAULT 0,
  status TEXT DEFAULT 'pending',  -- pending, paid, defaulted
  payment_date TIMESTAMP,
  confirmed_by TEXT,
  confirmed_at TIMESTAMP,
  created_at TIMESTAMP DEFAULT now()
);
```

## Phase 7: WhatsApp Integration Analysis

### Current Situation
- You have a regular WhatsApp group (not WhatsApp Business)
- Members' phone numbers are stored in the app

### WhatsApp Integration Options

**Option A: Link to Existing WhatsApp Group (Recommended - Simplest)**
- Simply add a "Join WhatsApp Group" button in the app
- Links to your existing WhatsApp group: `https://chat.whatsapp.com/your-invite-code`
- Members click → opens WhatsApp → joins group
- No API costs, no setup needed
- Currently the best approach for your situation

**Option B: WhatsApp Business API (For Future)**
- Requires: WhatsApp Business account + Meta Developer account
- Can send automated messages (payment reminders, draw notifications)
- Can receive replies back into app chat
- Costs: ~$0.01-0.05 per message
- Setup time: 1-2 weeks for approval

**Option C: SMS Fallback**
- Use SMS for important alerts (Uganda telcos: MTN, Airtel)
- Less reliable than WhatsApp but works for members without smartphone data

### Recommended Next Steps

1. **Now**: Add "Open WhatsApp Group" button linking to your existing group
2. **Later**: Consider upgrading to WhatsApp Business for automated messages

### Implementation for Option A
- Add button in sidebar/chat area: "Join WhatsApp Group"
- Store WhatsApp group invite link in group settings
- One-time setup, no API needed
